## Portforward

A useful command-line tool for developers.

### Installation

```bash
git clone https://github.com/simplestar-992/portforward.git
cd portforward
go build -o portforward .
```

### Usage

```bash
./portforward --help
```

---

## Quick Start

```bash
./portforward [command]
```
