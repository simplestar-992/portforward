# PORTFORWARD

**Useful CLI tool for developers**

## Features

- 🚀 Fast and efficient
- 📦 Single binary, no dependencies  
- 🔧 Easy to use
- 🔒 Secure by design

## Installation

```bash
git clone https://github.com/simplestar-992/portforward.git
cd portforward
go build -o portforward .
```

## Usage

```bash
./portforward --help
```
