## ✨ Features

- 🚀 Blazing fast performance
- 💎 Clean and intuitive API
- 🔧 Zero configuration needed
- 🛡️ Secure by default
- 📦 Single binary, no dependencies

## 📥 Installation

```bash
git clone https://github.com/simplestar-992/portforward.git
cd portforward
go build -o portforward .
./portforward --help
```

## 🚀 Quick Start

```bash
./portforward -h
```

## 🧪 Examples

```bash
# Example 1
./portforward status

# Example 2  
./portforward --verbose

# Example 3
```
